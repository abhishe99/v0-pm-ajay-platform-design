# PM-AJAY platform design


## Overview
  PM-AJAY Dashboard, a centralized digital platform for the
  management of the Adarsh Gram, GIA, and Hostel components of
  the PM-AJAY scheme. This solution aims to transform the current
  fragmented system into a transparent, efficient, and wellcoordinated digital framework.

## Key Features
•Centralized Agency Mapping: Create a digital repository of all implementing and executing
agencies across states and UTs. This provides a clear, structured view of roles and
responsibilities for each project.

•Fund Tracking: A digital dashboard to monitor the real-time flow of funds from the Centre to
the States/UTs and down to the executing agencies. This ensures transparency and helps in
timely fund release.

•Role-based Access & Accountability: Assign clear roles, timelines, and responsibilities to
each stakeholder through the platform. This reduces administrative delays and improves
accountability.

•Integrated Communication Module: A secure, in-built communication system for all
stakeholders (Centre, States/UTs, and executing agencies) to facilitate seamless and
transparent communication, reducing coordination bottlenecks.

•Project Progress & Milestone Tracking: Real-time tracking of project progress and
milestones. This provides a comprehensive overview of the status of each component and
allows for better implementation oversight.
